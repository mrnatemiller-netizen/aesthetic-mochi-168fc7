# The Divide — live RSS build
Upload these files to the root of GitHub repository `aesthetic-mochi-168fc7`. Netlify should use branch `main`, blank build command, publish directory `.`.
Live headlines are retrieved from configured RSS feeds using rss2json.com (third-party service, availability/rate limits may vary). This build has search, outlet perspective filters, source links, and periodic refresh. It does not yet include AI story matching, fact checking, user accounts, or a server-side backend.
