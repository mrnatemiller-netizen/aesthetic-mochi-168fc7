# The Divide — Live RSS build
Upload these files to the root of GitHub repository `aesthetic-mochi-168fc7`.
Netlify settings: branch `main`, blank build command, publish directory `.`.
Live headlines load from RSS feeds through proxy.cors.dev; browser refreshes every 15 minutes.
This is a live headline aggregator—not AI topic matching, fact-checking, or a backend. Third-party proxy/feed availability can vary.
